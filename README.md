# 🛒 Amazon Home Page Clone

A simple and clean clone of the **Amazon India homepage**, built using **HTML, CSS, and JavaScript**.
This project is perfect for beginners who want to practice front-end skills and understand how real-world e-commerce UI works.


## 📌 Features

✔️ Fully responsive design
✔️ Amazon-like header, search bar, and product sections
✔️ Product cards with hover effects
✔️ Slider / Banner section
✔️ Clean and beginner-friendly code
✔️ Organized folder structure

## 🛠️ Tech Used

| Technology         | Purpose                      |
| ----------------   | ---------------------------- |
| 🧱 **HTML**        | Page structure               |
| 🎨 **CSS**         | Styling & layout             |
| ⚡ **JavaScript**  | Slider, events, interactions |


## 📂 Project Structure

```
📁 amazon-clone/
│── style.css            # styles
│── index.html           # main file
│── README.md
```

## 📖 How to Run the Project

1. Download or clone this repo

   ```bash
   git clone https://github.com/Kuldeep-Makwana/Amazon-Clone.git
   ```
2. Open the folder
3. Simply open **index.html** in any browser
4. Done! 🎉
